# week/ui

Präsentationsbausteine der Woche. Werte rein, Absichten raus, kein Store.

- `WeekGridView`-Bausteine aus `week-grid-view.ts`: `buildColumns`, `BlockView`, `DayColumnView`,
  Maße der Griffe (`HANDLE_*`, `BLOCK_MIN_HEIGHT_PX`) und `billedNote`.
- `EntryPanel` (`app-entry-panel`): Detail-Panel mit Projekt, Tag, Von, Bis und Notiz. Ob
  gespeichert werden darf und wohin der Fokus geht, entscheidet die Seite.

Tags: `domain:week`, `type:ui`. Genutzt von `week/feature`.
