# projects/ui

Inline-Zeilen der Projektverwaltung, ersetzen die früheren Dialoge. Rein präsentational.

- `ClientRow` (`tr[app-client-row]`), `ProjectRow` (`tr[app-project-row]`): Anzeige und
  Bearbeiten einer Zeile
- `NewRow` (`tr[app-new-row]`): Leerzeile zum Anlegen, klappt beim Tippen auf
- `RowEditor` (`app-row-editor`): gemeinsamer Bearbeiten-Modus mit Hinweis „Ungespeicherte
  Änderungen"

Tags: `domain:projects`, `type:ui`. Genutzt von `projects/feature`.
