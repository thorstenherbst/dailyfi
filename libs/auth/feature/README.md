# auth/feature

Seiten für Anmeldung und Registrierung per Magic Link.

- `loadLoginPage` (`/login`), `loadRegisterPage` (`/register`), `loadCallbackPage`
  (`/auth/callback`): Lade-Funktionen für die lazy Routen in `app.routes.ts`. Die Komponenten
  selbst werden nicht exportiert.

Tags: `domain:auth`, `type:feature`. Genutzt nur von der App.
